Remarks

DSSC is a waveform/sample-oriented capture backend: it produces stored-vector (STV) style sample data and has no failing-cycle concept. Consequently ReadStv() returns the captured samples while ReadFails() always throws.

Shared signal collection: the DSSC capture signals are owned per pins+pattern combination, not per DsscCapture instance. Multiple instances created for the same pins and pattern (but different signal names) share one underlying Capture.Signals collection, and Reset() clears the whole collection. See Reset() for the implications.

Typical usage sequence:

  1. Create the capture (configures the DSSC signal on the hardware immediately).
  2. Execute a pattern burst.
  3. Call ReadStv() to retrieve the captured waveform samples.
  4. Call Reset() to release the configured signal after processing.

public void Reset()

Remarks

The IG-XL DSSC driver exposes no way to remove an individual signal, so this calls Capture.Signals.Reinitialize(), which clears every signal configured on this pins+pattern combination — not just Tol.DsscCapture._signalName. If several DsscCapture instances share the same pins and pattern with different signal names, calling Reset() on one instance will also discard the others' configured signals. In that scenario, read all signals before resetting any of them.
