Remarks

Construct instances via Factory helpers:

  • CreateCmemFailsCapture — captures failing cycle indices (Teradyne.Igxl.Interfaces.Public.CmemCaptType.Fail).
  • CreateCmemStvCapture — captures raw device data (Teradyne.Igxl.Interfaces.Public.CmemCaptType.STV).
  • CreateCmemCapture — full control over all parameters.

Typical usage sequence:

  1. Create via a Factory helper (configures CMEM hardware immediately).
  2. Execute a pattern burst.
  3. Call ReadFails() or ReadStv() to retrieve captured data from hardware into FailingCycleData or DeviceData.
  4. Call Reset() to release hardware resources after processing.

Parameters

captureType CmemCaptType

The capture mode. Must be Teradyne.Igxl.Interfaces.Public.CmemCaptType.Fail or Teradyne.Igxl.Interfaces.Public.CmemCaptType.STV; Teradyne.Igxl.Interfaces.Public.CmemCaptType.None and Teradyne.Igxl.Interfaces.Public.CmemCaptType.All are not allowed.

captureSource tlCMEMCaptureSource

The hardware data source. Must be compatible with captureType:

  • Teradyne.Igxl.Interfaces.Public.CmemCaptType.Fail: PassFailData or PatPassFailData.
  • Teradyne.Igxl.Interfaces.Public.CmemCaptType.STV: DutData or PatDutData.
digitalPins IDigitalPins

Pins used to retrieve data during Tol.CmemCapture.Read<T>(). Required for reading captured data.

returnValues int

Number of expected return values per word. Used together with wordSize to compute the STV capture buffer size (returnValues × wordSize). Ignored for Teradyne.Igxl.Interfaces.Public.CmemCaptType.Fail.

wordSize int

Width of each word in bits. Used together with returnValues to compute the STV capture buffer size. Ignored for Teradyne.Igxl.Interfaces.Public.CmemCaptType.Fail.

captureSize int

Maximum number of cycles to store in CMEM. Defaults to 4096. Applies to Teradyne.Igxl.Interfaces.Public.CmemCaptType.Fail only; STV size is derived from returnValues and wordSize.

captureLimit int

Maximum number of captures before the hardware stops recording. Set to 0 (default) for unlimited captures.

fullSpeed bool

When true, captures at full pattern speed without inserting wait cycles.

vectorOffset bool

Reserved for future use; not currently applied to SetCaptureConfig.

pattern string

Pattern name to associate with this capture. Pass an empty string (default) for any pattern.

timeDomain string

Digital time domain name to configure. Pass an empty string (default) to use the default time domain.

Exceptions

ArgumentException

Thrown when captureType is Teradyne.Igxl.Interfaces.Public.CmemCaptType.None or Teradyne.Igxl.Interfaces.Public.CmemCaptType.All, or when captureSource is incompatible with captureType.
