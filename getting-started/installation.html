Installation & Adding Reference

Once you've downloaded and extracted the Csra package, the next step is to integrate it into your development environment. Whether you're working in Visual Studio or using IG-XL, the process is straightforward. Below are the instructions for both environments to help you get up and running quickly.

How to Add C#RA to a New Test Program

C#RA is distributed as a source code package (zip download from GitHub Releases). Reference it by copying the Core folder — which holds both Csra and the Tol layer it depends on — next to your solution.

Step-by-step

  1. Download the release package from GitHub Releases. Choose a specific tagged version (e.g., v0.19.0).

  2. Extract and copy the Core folder from the downloaded zip to a location next to your solution file. Keep Csra and Tol together — Csra.csproj references Tol.csproj by relative path:

    MyTestProgram/
├── MyTestProgram.sln
├── MyTestProgram/
└── Core/          ← Place here
    ├── Csra/
    └── Tol/

  3. Add the project reference in Visual Studio:

    • Right-click the solution → Add > Existing Project...
    • Navigate to Core/Csra and select Csra.csproj
    • Repeat for Core/Tol/Tol.csproj
    • Click OK

  4. Record the version you added. Create or update a comment in your solution's README.md:

    ## Dependencies
- C#RA v0.19.0 — downloaded from GitHub Releases tag `v0.19.0`

  5. Commit everything, including the Core folder, to your test program's source control. This ensures your program always builds against the exact version you tested.

Important

This applies to the library (Core/Csra and Core/Tol). The reference test methods in CsraTestMethods are meant to be copied into your own project, not referenced from C#RA. They are a starting point you are expected to adapt to your device — copying them means your edits are yours, and a later C#RA upgrade will not overwrite or conflict with them.

Tip

Always record the exact version tag in your solution's documentation. When you later need to update, you will know exactly what you are upgrading from.

IG-XL Reference

To reference the compiled Csra library in IG-XL:

  • Build the Csra project in Visual Studio to generate the Csra.dll.
  • Open IG-XL.
  • Navigate to ReferenceSheet.
  • Right-click on the next empty cell, Edit.
  • Navigate to the output folder and select Csra.dll.
Note

This step registers the assembly that contains the TestMethods you want to call from the Test Instance Sheet. It is not a prerequisite for using C#RA itself — the library, TheLib and the services can be called from your own C# test methods without adding a Csra.dll reference here.
