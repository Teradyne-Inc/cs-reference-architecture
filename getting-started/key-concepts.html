Key Concepts

Pins — The Universal Pin Abstraction

Pins is an abstraction on top of the IG-XL pin list. Where IG-XL gives you a comma-separated string that you have to re-interpret at every call site, Pins turns that same string into a resolved, strongly-typed object once — and that object is what every C#RA block takes as input. You construct it from an ordinary IG-XL pin list string:

var pins = new Pins("VDD, VCC_IO, DATA_BUS");

Under the hood, Pins resolves pin groups, detects each pin's instrument type, and exposes instrument-specific accessors:

Accessor Instrument Type Typical Use
pins.Ppmu Per-Pin Measurement Unit (UP2200/UP5000) Small-signal DC on digital pins
pins.Dcvi DC Voltage/Current Instrument (UVI264) High-accuracy DC parametric
pins.Dcvs DC Voltage Source (UVS64/UVS256/UVS64HP) Power supply pins
pins.Digital Digital channel hardware Pattern I/O, levels, timing

The library blocks (Setup.Dc, Acquire.Dc, etc.) automatically route calls to the correct instrument based on the pin content — you rarely need to deal with instrument types directly.

PatternInfo — Wrapping Digital Patterns

var pat = new PatternInfo("my_pattern_set", threading: true);
TheLib.Execute.Digital.RunPattern(pat);

PatternInfo loads the pattern, manages threading validation, and stores the time domain and CPU flag configuration needed for conditional stops.

Settings and Setups — Declarative Hardware Configuration

Instead of imperatively calling hardware APIs, you can declare Settings (type-safe wrappers, one per instrument feature) and group them into named Setups:

Setup normal = new("Normal");
normal.Add(new Csra.Setting.TheHdw.Dcvi.Pins.Voltage(1.8, "VDD"));
normal.Add(new Csra.Setting.TheHdw.Dcvi.Pins.Voltage(3.3, "VCC_IO"));
Services.Setup.Add(normal);

// Later, in a test method:
Services.Setup.Apply("Normal");

Setting class names mirror the IG-XL driver language (Csra.Setting.TheHdw.<Instrument>.<Node>.<Feature>), so Dcvi.Pins.Voltage maps directly to the DCVI voltage node. The SetupService tracks what was previously applied and only sends changed values to hardware (a diff-and-apply model) — see Setup Service for the full picture, including Audit Mode.
