Repository Layout

This is the layout of the C#RA source you receive — the same content you can browse at Teradyne-Inc/cs-reference-architecture and the same structure you get after extracting the release package.

cs-reference-architecture/
│
├── Core/                         ← Core library projects
│   ├── Csra/                     ← The core library (start here!)
│   │   ├── Api.cs                ← Single entry point: Api.TheLib / Api.Services
│   │   ├── Csra.csproj           ← References ..\Tol\Tol.csproj
│   │   ├── TestBlocks/           ← All test block interfaces and implementations
│   │   │   ├── ITestBlocks.cs      ← Interface definitions for all blocks
│   │   │   ├── TestBlockManager.cs ← Wires up the default implementations
│   │   │   ├── Validate.cs         ← Input validation (parameter checks)
│   │   │   ├── Datalog.cs          ← Result logging to IG-XL flow
│   │   │   ├── Setup/            ← Hardware configuration (Dc, Digital, LevelsAndTiming)
│   │   │   ├── Execute/          ← Pattern execution (Digital, ScanNetwork, Search, Wait)
│   │   │   └── Acquire/          ← Measurement capture (Dc, Digital, ScanNetwork, Search)
│   │   ├── Services/             ← Cross-cutting infrastructure (interface + impl per subfolder)
│   │   │   ├── Alert/            ← IAlertService.cs + Alert.cs — logging, error handling
│   │   │   ├── Behavior/         ← IBehaviorService.cs + Behavior.cs — runtime feature flags
│   │   │   ├── Storage/          ← IStorageService.cs + Storage.cs — persistent key-value store
│   │   │   └── SetupService/     ← ISetupService.cs + SetupService.cs — named config management
│   │   ├── Types/                ← Shared data types (organized into subfolders)
│   │   │   ├── Core/             ← BiDictionary, Enums, IExecutable, PatternInfo, Setup
│   │   │   ├── Pins/             ← Pins, PinsFactory
│   │   │   ├── HardwareParameters/ ← DcParameters, DigitalParameters
│   │   │   └── ScanNetwork/      ← Scan network pattern info & results
│   │   ├── Settings/             ← SettingBase + Setting_bool/_int/_double/_Enum + ISetting
│   │   └── Extensions/           ← Helper extension methods
│   └── Tol/                      ← Thin Object Layer (TOL) — per-instrument pin abstractions
│                                   that Csra routes through (PPMU, DCVI, DCVS, Digital)
│
├── ReferenceLibraries/           ← Test method library projects
│   ├── CsraTestMethods/          ← Reference test methods BUILT ON the C#RA library
│   │   ├── Capture/              ← CMEM, DSSC & HRAM capture
│   │   ├── Continuity/           ← Contact & short checks
│   │   ├── Functional/           ← Digital pattern tests
│   │   ├── Leakage/              ← Leakage current measurement
│   │   ├── Parametric/           ← General DC parametric
│   │   ├── Resistance/           ← Contact resistance & RdsOn
│   │   ├── ScanNetwork/          ← IJTAG scan network tests
│   │   ├── Search/               ← Voltage/functional threshold search
│   │   ├── SupplyCurrent/        ← Static & dynamic IDD
│   │   ├── Timing/               ← Frequency measurement
│   │   ├── Trim/                 ← Digital trim algorithms
│   │   ├── CustomCode/           ← Extensibility example (IExecutable)
│   │   ├── Showcase.cs           ← Extension-method and customization examples
│   │   └── CustomerExtensions.cs ← Where your own extension methods go
│   ├── CsTestMethods/            ← Raw C# test methods (direct IG-XL API calls, no C#RA)
│   ├── UnitTests/                ← Example unit test project + reusable Base class
│   └── PortBridge/               ← PortBridge utilities and demo
│
├── Demo/                         ← IG-XL demo program (see Download & Extract)
├── csra_documentation.pdf        ← Offline documentation
├── LICENSE.txt
└── README.md
Note

This is what is published. The development repository additionally contains the C#RA project's own unit and system-integration tests, CI configuration and internal documentation, none of which are delivered.
