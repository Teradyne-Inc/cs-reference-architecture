Available Test Methods

The ReferenceLibraries/CsraTestMethods project provides reference test methods that you can change or reuse. Each follows the four-phase pattern and can be used directly in IG-XL, copied into your own project, or adapted to your device. This is where the ~70% reusable code lives — the common measurement patterns that work across different chips and customers.

CsTestMethods vs CsraTestMethods — Understanding the Difference

The repository contains two projects with similar test categories (Continuity, Functional, Leakage, etc.):

Project Approach Recommendation
ReferenceLibraries/CsTestMethods/ Calls IG-XL public APIs directly in straight C# Usable, but not recommended — the code is tied to one device and has to be rewritten for the next program
ReferenceLibraries/CsraTestMethods/ Calls the C#RA library (TheLib, Services) Recommended — reusable across projects, typically only ~30% customization needed

Both projects are available to you and both produce the same end result (a working test program). The difference is what happens next: CsraTestMethods goes through the C#RA abstraction layer, which keeps the implementation portable and maintainable across multiple programs, while CsTestMethods serves as a baseline comparison showing what the raw, non-C#RA approach looks like. Start from CsraTestMethods unless you have a specific reason not to.

The Catalog

To use one of these, you type its full name into the IG-XL Test Instance Sheet, in the form CsraTestMethods.<Category>.<Class>.<Method> — for example CsraTestMethods.Continuity.Parametric.Parallel. Reference the Library

Before using a Test Method from the C#RA library, make sure you've completed the IG-XL Reference step. This ensures that IG-XL can access the compiled Csra.dll and recognize the available TestMethods.

  • Open IG-XL.
  • Navigate to the Test Instance Sheet.
  • Enter the desired Test Method name (e.g., CsraTestMethods.Continuity.Parametric.Parallel).
  • Provide the required parameters for the selected method.
  • Run IG-XL to execute the test.
